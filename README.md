# OpenAI SDK

## Requirements

- Python 3
- An OpenAI API key

## Setup

1. Create and activate a virtual environment:

   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   ```

2. Install the project dependencies:

   ```bash
   pip install -r requirements.txt
   ```

3. Create an API key in the [OpenAI Platform](https://platform.openai.com/api-keys).
